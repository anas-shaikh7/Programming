Transition: To go from one state to another smoothly

transition-property: transform; transition-duration: xs; transition-timing-function: ease; transition-delay:xs;
This is how you give transition.

transition-property: transform, scale, background-color; -- You can change multiple things at the same time

Use dev tools to adjust the smoothness according to your preference

transition: all 4s cubic-bezier(0, 0.68, 0.36, 0.98) 1s; -- shorthand tool to apply every property at the same time
