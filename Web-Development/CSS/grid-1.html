Grid Properties

grid-template-columns: and grid-template-rows: determine the number and size of columns and rows in a CSS grid layout. For example, grid-template-columns: 120px 100px; creates two columns with widths of 120px and 100px, while grid-template-rows: 70px 70px 70px; creates three rows, each 70px tall.

grid-row: 1/3 or grid-row-start: 1; grid-row-end: 3; both achieve the same result. The first is a shorthand for specifying the start and end lines: Format: grid-row: start/end;

justify-items and align-items are CSS grid container properties. - justify-items controls the alignment of grid items along the row (inline) axis. - align-items controls the alignment of grid items along the column (block) axis. Both properties are set on the grid container, not on individual grid items.
place-items: center; – This property is a shorthand for setting both align-items and justify-items on the grid container. It centers grid items both vertically (block axis) and horizontally (inline axis) within their grid areas.

align-self: start; and justify-self: end; are CSS item properties used to control the positioning of individual grid items within their grid area.

align-content and justify-content are CSS grid container properties used to align the entire grid within the container when the grid does not fill all available space. - align-content positions the grid along the block (vertical) axis. - justify-content positions the grid along the inline (horizontal) axis. These properties only have an effect if the grid is smaller than the container. place-content: center or something else; – This property is a shorthand for setting both align-content and justify-content in the grid container. It centers the grid both vertically (block axis) and horizontally (inline axis) within the container.

grid-template-columns: repeat(3, 1fr); – Use repeat() to apply the same size to multiple columns or rows, which helps avoid repetition in your CSS.

grid-template-columns: repeat(3, minmax(100px, 2fr)); The `minmax()` function is useful when you want a grid track (column or row) to be flexible, but not shrink below or grow above certain limits. It comes in use when: - You want columns/rows to be responsive, but not smaller than a minimum or larger than a maximum. - You want to avoid items getting too small on small screens or too large on big screens. - You want to combine flexible sizing (`fr`) with fixed minimum or maximum values. This helps create layouts that are both flexible and user-friendly.
