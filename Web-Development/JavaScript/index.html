Variables

Variable is a contianer which containes a variable(number, object, string). variables is a global variable and gives output of whatever is applied later.

String: Collection of characters the variable in var "a" this "a" can digits, letters, underscores, dollar sign. It cannot start with a digit. AnaS and Anas are two different variables because javascript is case sensitive.

let is block scoped and takes whatever is given to it in the scope of its block. let can be updated/changed but not redecalred(declare something that is not in its scope) Const is also block scoped but cannot be updated or redeclared. It is a constant variable. Its used when you want something to stay the same in every case

Primitive data type is a set of datatypes which contains Boolean, Bigint, string, null, undefined, number, symbol. Object is not a primitive data type

Objects ---> are non-primitive data types. It is a collection of properties. Properties are key-value pairs. Key is always a string but value can be anything. The only exception of key not being a string is that it has no space between the words in the key. let o ={ value: key ---> key value pair name: "anas", "job role": "boss", age: 17 // "house Number": "your house" }
